### basics

pull all remote changes

```
git fetch --all
```

what branch am i on?

```
git branch
```

create new branch

```
git checkout -b <branch-name>
```

publish new branch and set upstream origin

```
git push -u origin <branch-name>
```

stage all changes

```
git add .
```

commit

```
git commit -m "your commit message"
```
